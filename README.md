# annotate-tool

COCO instance-segmentation アノテーションのビューア(PySide6)。
丸太の木口(log end faces)のセグメンテーション結果を画像に重ねて確認するためのツール。

## 起動

```sh
uv run src/main.py [path/to/instances.json]
# または(uv sync 後)
uv run annotate-tool [path/to/instances.json]
```

引数を省略すると前回開いた JSON を開き直す。それも無ければ何も開かずに起動するので、
右パネル最上段の「COCO JSON を開く…」で選ぶ(選んだパスは設定ファイルへ記録され、
次の起動で開き直される)。画像は JSON と同じディレクトリから `file_name` で解決される。

## 操作

| 操作 | キー / マウス |
| --- | --- |
| 前 / 次の画像 | ← / →。追加モード中は効かない |
| 画面にフィット | F |
| オーバーレイ表示切替 | V |
| 塗りつぶし切替 | B |
| 選択解除 | Esc |
| ズーム | ホイール(Ctrl+ホイール、タッチパッドのピンチでも可) |
| パン | 中ボタンドラッグ、または Space+左ドラッグ |
| インスタンス選択 | ポリゴンをクリック、または左の一覧をクリック |
| 複数選択(追加 / 解除) | Shift + クリック |
| 矩形選択 | 左ドラッグ(矩形に触れたインスタンスを選択へ追加) |
| 選択インスタンスを削除 | Delete(または上部の「削除」ボタン) |
| 選択インスタンスを修正 | E(または上部の「修正」ボタン。単一選択のときだけ) |
| インスタンス追加(開始) | A(または上部の「追加」ボタン。未選択のときだけ) |
| 追加モードで塗る / 消す | 左ドラッグ(左上で選んだブラシ / 消しゴム) |
| パスで頂点を打つ | 左クリック(ツールパネルで「パス」を選ぶ) |
| パスを閉じる | 最初の頂点をクリック、ダブルクリック、または Enter |
| 直前の頂点を取消 | Ctrl+Z(または Backspace) |
| ツール切替 | 1 ブラシ / 2 消しゴム / 3 パス(追加モード中のみ。左上のツールパネルでも切替可) |
| 太さ | 左上のツールパネルのスライダー(ツールごとに独立) |
| 追加を確定 | S / Enter(または塗り始めると出る「確定」ボタン)。塗る前は効かない |
| 追加を取消 | Esc(または追加中に出る「キャンセル」ボタン)。パスを作図中は、まずパスだけが取り消される |

### タッチパッドモード

右下の「操作方法」欄にある「タッチパッドモード」を ON にすると、
ホイール(2本指スクロール)がズームではなくパンになる(欄の案内文も
モードに合わせて切り替わる)。ズームはピンチまたは
Ctrl+ホイールで行う(Windows のタッチパッドはピンチを Ctrl+ホイールとして
届けるため、どちらも同じ動きになる)。既定は OFF(ホイール=ズーム)。
マウスとタッチパッドはイベントだけでは確実に区別できないため、自動判別では
なく設定で切り替える方式にしている。

macOS のピンチと Space+左ドラッグのパンは、モードの ON/OFF に関わらず常に使える。
なお Space をショートカットに割り当てている場合はそちらが優先され、
Space+ドラッグのパンは効かない。

### ショートカットの変更

キー割り当ては設定ファイルで変更できる。右下の「キーボードショートカット設定」
ボタンで保存先フォルダが開く(`%APPDATA%\tree-log\annotate-tool.ini`)。初回起動時に
既定値が書き出されているので、`[shortcuts]` セクションの値を書き換えて再起動する。

```ini
[shortcuts]
add=Q
edit=ctrl+e
next_image=Right, D, Space
```

- 値はキー名。複数割り当てるならカンマ区切りで、**先頭がボタンに表示される代表キー**
- `ctrl+e` や `escape` のような表記ゆれは吸収される(`Ctrl+E` / `Esc` として扱う)
- **同じキーを2つの操作へ割り当てない**。Qt は重複したキーをどちらも発火させない
  ため、検出した時点で `[shortcuts]` の指定をすべて無視して既定へ戻す
- 解釈できない値の行は、その行だけ無視して既定へ戻す

いずれの場合も理由がステータスバーへ出る。起動は止まらない。

## 構成

```
src/annotate_tool/
├── app.py            # エントリポイント(引数解析・起動)
├── coco_data.py      # GUI 非依存の COCO データモデル / IO
├── tools.py          # 描画ツールの識別子(Tool.BRUSH / ERASER / POLYGON)
├── state.py          # ViewerState: アプリ状態の一元管理(single source of truth)
├── style.py          # 色・スタイル・レイアウト定数
└── widgets/
    ├── main_window.py     # 組み立てと配線のみ(composition root)
    ├── image_view.py      # 画像 + ポリゴン描画ビュー
    ├── instance_panel.py  # インスタンス一覧ドック(左)
    ├── side_panel.py      # 操作パネル・ドック(右)
    ├── control_group.py   # 見出し付きボタングループ(移動 / 表示)
    ├── action_bar.py      # 浮動アクションバー(選択解除 / 修正 / 削除)
    ├── add_bar.py         # 浮動バー(追加 / キャンセル / 確定)。塗りつぶしで新規追加
    ├── tool_panel.py      # 左上の浮動パネル(ブラシ / 消しゴム / パスのトグルと太さ)
    └── brush_slider.py    # 太さスライダー(tool_panel の各行に並ぶ)
```

設計方針:

- 状態(現在画像・選択・表示フラグ)は `ViewerState` だけが持つ。
  ウィジェットは操作を `ViewerState` のメソッド呼び出しに変換し、
  表示更新はシグナル経由で受け取る。
- `coco_data.py` は Qt に依存しないため、将来の編集・保存機能や
  CLI ツールからもそのまま使える。
- 見た目の定数は `style.py` に集約。
